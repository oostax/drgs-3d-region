# 3D-компас

Кнопка компаса слева раскрывает один компактный инструмент, не меняя положение,
масштаб карты, выделение или открытую карточку.

- Кольцо: перетаскивание по окружности вращает карту без скачка через север/юг.
- Центр: вверх/вниз меняет наклон, влево/вправо — направление.
- Двойной клик по кольцу возвращает север вверх; по центру — вид сверху.
- Стрелки: шаг 5°, с Shift — 15°. Home сбрасывает соответствующий угол.
- В 2D доступно направление, наклон остаётся 0°. В 3D предел наклона 75°
  на широком экране и 60° на компактном/сенсорном устройстве.
- Escape или повторное нажатие закрывают компас; клик вне него тоже закрывает.

В меню «Карта» убран дублирующий ползунок наклона. Жест из трёх пальцев отдельно
не перехватывается: используется обычное перетаскивание указателем по компасу
(мышь, трекпад с зажатым нажатием, сенсорный экран). Настройки жестов macOS не меняются.

Управление работает через публичные методы MapLibre, а не диагностический
`window.__atlasMap`. Очередь движения ограничена одним обновлением за кадр;
промежуточные движения не перестраивают маркеры в родительском обработчике.
Pointer capture, pointercancel, потеря фокуса, смена режима и скрытая вкладка
завершают взаимодействие. Выбор 2D/3D не выводится из текущего наклона.

Проверки: `npm test`, `npm run typecheck`, `npm run build`.
`python3 scripts/verify-compass.py` проверяет настоящий интерфейс/MapLibre,
кольцо, центр, выход указателя за границы, клавиатуру, touch, открытые карточки
и размеры 1440→390→1440. Как и `verify-analytics.py`, запускается против
синтетических локальных источников из `scripts/prepare-analytics-fixture.ts`.
Это не проверка физического трекпада или полного локального набора пользователя.
