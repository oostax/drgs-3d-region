# Журнал проверок

Дата фиксации: **4 сентября 2026 года**. Это запись фактически выполненных проверок, а не утверждение о готовности последней production-сборки. Основание — результаты команд и API в текущей работе, тестовые файлы, импортные отчёты и подтверждённые браузерные наблюдения основной задачи. При этой документационной доводке код, сборка и серверы не запускались и не менялись.

## Реальный локальный импорт и HTTP API

Все 12 пользовательских XLSX обработаны локально; повтор тех же хэшей пропустил уже завершённые источники. В проверенном состоянии реестр содержал 12 завершённых импортов, без выполняющихся или ошибочных. Контрольные числа относятся к разным сущностям и не складываются:

| Сущность | Подтверждённое значение |
| --- | ---: |
| Организации и строки ФОТ пилота | 11 408 |
| Организации со счётчиками встреч | 7 708 |
| Равные повторы строк встреч, учтённые один раз | 4 099 |
| Квартальные суммы встреч | 382 / 426 / 341 |
| Текущие предложения | 2 011 |
| Предложения q1 / q2 / q3 | 18 479 / 14 797 / 16 797 |
| Обращения Татарстана | 6 374 |
| Группы «муниципалитет + тема» в региональном ответе | 438 |
| Версии штата | 570 и 569 строк |

Через HTTP на `127.0.0.1:3200` проверены:

- `/api/health`: успешный ответ сервиса.
- `/api/atlas?mode=work`: 6 374 обращения, 2 011 текущих предложений, 11 408 организаций, встречи 382/426/341; доступны все 438 групп.
- `/api/operations?mode=work`: 12 завершённых источников; версии штата и фильтры исходных банковских сводок сохранены отдельно.
- `/api/incidents?mode=work`: 50 записей на странице из 6 374, без сокращения полного количества до первой страницы.
- Публичный atlas: внутренних сигналов нет, финансовые и внутренние счётчики — `null`. Публичные operations и planning — `null`, incidents и organizations — пустые. Карточка внутренней организации в публичном режиме — `null`.
- Посторонние Host/Origin, `Sec-Fetch-Site: cross-site`, поддомен-имитация localhost и `Origin: null` отклонены с 403. Запрос с допустимым локальным Origin прошёл. Это проверка конкретных ограничений локального приложения, а не аудит корпоративной авторизации.
- Карточка организации возвращает изменения между соседними срезами и подпись предполагаемой даты источника. При отсутствии данных сравнение недоступно; ожидаемый доход не превращается в ноль.

Полные ключи и семантические ограничения находятся в [IMPORT.md](IMPORT.md). ФОТ — рубли; ОД — ожидаемый доход, а не фактическая выручка. Текущий срез отобран по ГОСБ 8610, история — по ИНН пилотного списка; это не доказательство исторической принадлежности к ГОСБ.

## Адреса, возможности и планы

Через реальный локальный endpoint сопоставления сохранены **5 точных совпадений ИНН и 1 конфликтный кандидат**. Открытый индекс содержит 6 записей, у 4 есть координаты зданий. Ответ planning содержит страницу из 40 организаций, 6 записей с адресами/кандидатами и 6 вариантов КМ. Публичный ответ проверен как `null`.

Ручное подтверждение адресов и создание планов проверены **на синтетических организациях**: место встречи сохраняется отдельно от юридического адреса и переживает повторное сопоставление открытого индекса. Закрытые на ремонт учреждения не получают автоматически согласованное место встречи. Для реальных клиентов подтверждённые места и встречи автоматически не создавались.

Проверены ближайший порядок точек, явные оценки расстояния, московское время, буферы, сохранение и чтение плана, неоднозначный КМ, `NULL`/ноль в правилах. Незавершённая или ошибочная свежая загрузка ФОТ/встреч не порождает новые факты соответствующих правил. Полный новый браузерный цикл ручного адреса → план → дорожное уточнение → карта остаётся отдельной проверкой.

## Сеть, кэш и дорожный сервис

**Подложка:** шесть тестов выполнялись с временным кэшем и заглушкой сети. Восемь недопустимых путей отклонены до fetch; четыре семейства `planet`, `fonts`, `sprites`, `natural_earth` направлены на фиксированный OpenFreeMap. Query, тело и заголовки клиента не пересылаются. Встроенный URL в сегменте кодируется и не меняет адрес назначения.

Сохранённый бинарный тайл повторно получен побайтно при недоступной сети с **нулём попыток обращения к upstream**. TileJSON проверен для локальных адресов 127.0.0.1 и localhost. Для отсутствующего тайла сетевой сбой дал 503, ответ upstream 500 дал 502; пустой файл не создан. Это доказывает работу уже сохранённого кэша, а не наличие всей подложки офлайн.

**OSRM:** проверены фиксированный endpoint, передача только координат, запрет редиректов, необходимость явного согласия, пересчёт расписания по участкам и сохранение метода/геометрии. При недоступности провайдера остаётся обозначенная оценка с сообщением о сбое.

Отдельный **реальный** запрос по двум публичным координатам из [документации OSRM](https://project-osrm.org/docs/v5.24.0/api/#route-service) вернул `Ok`, `LineString` из **133 точек**, один участок. Частные названия, ИНН и координаты клиентов в этой проверке не отправлялись. Этот запрос подтверждает доступность сервиса в момент проверки, но не качество всех маршрутов Татарстана и не учёт пробок.

## Открытые условия готовности

- [ ] **Новая production-сборка.** Выполнить после окончания изменений движения; старый успешный build не подтверждает новую версию.
- [ ] **Приватность состава пакета.** Проверить актуальные `*.nft.json` и `.next/standalone`: нет SQLite, WAL/SHM, XLSX и приватных загрузок. На предыдущем этапе в старой сборке были обнаружены 3 приватных файла до исправления исключений; наличие настроек в `next.config.ts` само по себе не закрывает проверку нового результата.
- [ ] **Актуальные общие тесты и typecheck.** Повторить после последней интеграции solar/planning/traffic, записать реальный итоговый состав.
- [ ] **Desktop браузер.** Целиком проверить новую компоновку, непрерывный zoom, часы/освещение, редактор адресов, возможности, план, OSRM и возвраты между панелью и картой.
- [ ] **Mobile браузер.** Проверить текущую версию на узком viewport: жесты, раскрытие/закрытие панелей, отсутствие перекрытия управления и горизонтального переполнения. Это ещё не тест физического смартфона.
- [ ] **Новое движение.** Проверить стабильность машин/людей/других объектов при смене масштаба, плотность и траектории, остановку в скрытой вкладке, reduced-motion и выключение симуляции. Слой не должен выглядеть как источник реального трекинга.
- [ ] **Ошибки и fallback нового UI.** Повторить потерю сети, недоступный тайл, `/?webgl=0` и смену режима после последних изменений карты.
- [ ] **Production-перезапуск и сохранение.** Перезапустить итоговый сервер, открыть ранее сохранённые досье/планы, проверить заметки, источники, публичный режим и печать.

Не проверялись: физический смартфон и его FPS/нагрев/память; адреса всех 11 408 организаций; все реальные здания; полнота действующих отделений и банкоматов; реальные календари КМ; фактическое время в пробках; согласование встреч и доступность финансовых продуктов конкретным клиентам.
