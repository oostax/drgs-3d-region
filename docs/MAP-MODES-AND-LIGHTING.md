# Режимы карты и закатное освещение

## Два режима, одно состояние

2D — плоская схема без декоративных текстур зданий. 3D — объёмные здания с текстурами фасадов и крыш. Отдельный третий режим не вводится: для работы с маркерами и маршрутами используется схема, для пространственного обзора — объём.

Причина прежней непоследовательности: Atlas инициализировал `is3D = true`, а подпись кнопки проверяла ещё и наклон камеры. Начальный `pitch = 0` поэтому выглядел как 2D, хотя текстурные 3D-слои уже работали. При последующем выключении 3D показывался другой, действительно плоский слой.

Теперь `DEFAULT_MAP_3D = false`. Начальная загрузка, переключение, восстановление стиля и изменение размера окна используют общий `applyMapMode`. Кнопка показывает выбранный режим и `aria-pressed`, а не промежуточный наклон во время анимации. Один клик всегда меняет режим. В 2D максимальный наклон равен нулю и touch-pitch отключён; в 3D восстанавливаются ограничения 60° для компактного экрана и 75° для desktop. Обзор страны может оставаться видом сверху и в выбранном 3D: это положение камеры, а не дополнительный режим.

При переключении текстуры не удаляются, исходные высоты, этажность, геометрия и цвета материалов не переписываются. Остальная картографическая подложка и маркеры сохраняются.

## Закат без оранжевого фильтра

Раньше `SolarLightLayer` добавлял тёплую заливку даже на городском масштабе: до 16% поверх уже освещённой карты. Одновременно один и тот же насыщенный солнечный RGB использовался как направленный свет Three.js и как общий цвет освещения MapLibre, включая текстурные крыши.

Теперь на масштабе 9 и ближе дополнительная солнечная заливка не рисуется. На региональном масштабе остаётся слабый нейтрально-тёплый эффект не более 4%; географическая граница дня и ночи сохранена. MapLibre получает почти нейтральный `legacyColor`, а Three.js — отдельный мягкий тёплый `sunColor` и прежнее нейтральное окружающее освещение. Суточный цикл, положение солнца и ночные окна остаются; закат больше не перекрашивает все материалы одним оранжевым цветом.

## Обновление и запуск

Остановить работающий сервер через Ctrl+C в его терминале. В существующей папке проекта:

```sh
git switch master && git pull --ff-only origin master && npm ci && npm run dev
```

Открыть `http://127.0.0.1:3200` и перезагрузить страницу. Проверить: сразу чистый 2D; затем 3D с текстурами; возврат в такой же 2D. В панели времени сравнить день и закат. Локальные `.env`, базы и тайлы этим исправлением не изменяются.
