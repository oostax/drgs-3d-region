# Импорт данных атласа

Рабочие данные хранятся локально в `private-data/atlas.sqlite`, схема версии 1. Файлы XLSX читаются потоково средствами Python `zipfile` и XML. Таблица общих строк использует временный автоматически удаляемый файл и компактный индекс, поэтому крупная книга не загружается целиком в память. Исходные книги не изменяются.

`private-data` и загруженные книги не должны публиковаться вместе с приложением. Презентационный режим не читает финансовые данные, штат или внутренние сводки. `operationsData('public')` и `sourceStatus('public')` возвращают `null` до открытия SQLite.

## Правила показателей и сопоставления

- **Пилотный портфель:** объединение организаций из ФОТ, встреч и текущих предложений, закреплённых за ГОСБ 8610. В данных этой поставки объединение осталось равным 11 408 организациям. Текстовые обозначения «Банк Татарстан … № 8610» и числовой код `8610` приводятся к одному банковскому ключу.
- **География:** принадлежность к ГОСБ не является адресом организации. Текущие предложения отобраны по ГОСБ 8610; исторические книги не содержат ГОСБ и отбираются по ИНН уже известного пилотного портфеля. Эти исторические показатели нельзя называть результатами только ГОСБ 8610 или распределять по муниципалитетам без отдельной адресной связи.
- **ИНН:** ключ хранится строкой. Потерянный начальный ноль у 9- или 11-значного исходного значения восстанавливается только при прохождении контрольной суммы. Коллизии не объединяются автоматически; невалидные и отсутствующие ключи сохраняются со стабильным идентификатором и отметкой качества. В каждом файле ФОТ восстановлено 262 значения пилота, во встречах — пять строк; коллизий в этой поставке нет.
- **ФОТ:** месячные L:M и накопительные N:O показатели различаются. По подтверждению пользователя денежные значения представлены в рублях. Число получателей — исходный месячный счётчик; уникальность между месяцами и ГОСБ не предполагается. Импорт одного файла изменяет только принадлежащие ему поля, сохраняя поля второго файла. Пустое значение остаётся `NULL`, настоящий ноль — `0`.
- **Встречи:** одна запись на ГОСБ + ИНН. Из 11 807 строк Татарстана 4 099 повторяют одинаковые квартальные счётчики. После проверки равенства суммы составляют **382 / 426 / 341**. Различающиеся счётчики помечаются конфликтом и исключаются из итоговых сумм; их нельзя суммировать как независимые встречи.
- **Предложения:** сумма сделки и ОД — разные поля, обе суммы в рублях; ОД означает ожидаемый доход по подтверждению пользователя. Снимки `current`, `q1`, `q2`, `q3` сохраняются отдельно и не складываются. В расчёты поступает только последний успешно завершённый источник выбранного снимка; незавершённая замена не добавляет частичные суммы. Карточки связаны с предложениями по однозначному `org_id`, а не по совпадению ИНН само по себе.
- **Изменения предложений:** карточка сравнивает одну организацию по ID предложений с соседним предыдущим срезом (`current → q3 → q2 → q1`). Появление и исчезновение ID означает изменение состава выгрузок, а не доказательство создания или закрытия сделки. Если хотя бы в одном срезе нет данных организации, либо ID пустые/повторяются, сравнение недоступно. Изменение ОД считается только при заполненном доходе всех предложений обоих срезов. Историческая принадлежность к ГОСБ не подтверждена; это сравнение организации, а не динамика портфеля ГОСБ.
- **Даты снимков:** 31.03.2026, 29.06.2026, 21.08.2026 и 31.08.2026 используются как предполагаемые даты соответственно q1, q2, q3 и current. Это не подтверждённые даты отчётности; признак предположения хранится в метаданных. Месяцы/накопительные даты ФОТ читаются из заголовков. Год счётчика получателей и встреч связан с сопутствующей поставкой и также маркируется как предположение.
- **Штат:** версии сохраняются отдельно. Совпадают 569 табельных номеров, одна запись есть только в `штат.xlsx`; у 60 общих сотрудников различаются подразделение 05 уровня и/или назначенная роль (23 и 47 соответственно). В каждой версии шесть строк подразделения Татарстана. Эти версии не являются двумя группами сотрудников для суммирования. Указанный книгой период — 01.01–30.06.2026, время выгрузки — 02.06.2026 00:12:12.
- **Кластеры:** три строки без номера ГОСБ сохранены с ключами `unresolved`, а не потеряны. Номер кластера — категория из источника; величина 1–5 не трактуется автоматически как рейтинг эффективности.
- **Сводные обращения:** лист `d` содержит 14 строк с фильтром приоритета «несколько элементов», лист `все` — 15 строк с фильтром «Все». Это разные фильтрованные представления банковских подразделений. Состав выбранных элементов и год из этих таблиц не установлены; название файла не превращает листы в сравнение 2025 и 2026 годов. Строка общего итога помечается отдельно и не складывается с банковскими строками.
- **Адреса обращений:** из 6 374 записей у 3 837 нет улицы, у 6 082 нет объекта, у 1 655 нет населённого пункта. Муниципальные агрегаты показываются с точностью территории. Фиктивные координаты организаций или адресов не создаются. Все 438 сочетаний муниципалитета и тематической группы доступны API; список не обрезается до первых 50.

## Запуск и повторная загрузка

В интерфейсе доступны импорт известных файлов из `Downloads` и загрузка XLSX. Для нового среза сохраните типовое имя соответствующей книги. Внутренний UUID-префикс загруженного файла не меняет распознавание источника; в реестре сохраняется исходное понятное имя. Неизвестное имя отклоняется до запуска задания.

Для CLI удобно явно выбрать штатный Python Codex:

```sh
ATLAS_PYTHON="$HOME/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3"
"$ATLAS_PYTHON" scripts/import_xlsx.py --directory "$HOME/Downloads" --db private-data/atlas.sqlite
```

Один источник:

```sh
"$ATLAS_PYTHON" scripts/import_xlsx.py --file "$HOME/Downloads/Объем ФОТ (март, июль).xlsx" --db private-data/atlas.sqlite
```

Для книги с другим именем CLI допускает один `--file` и явный `--kind` из `--help`. При пакетном запуске организации пилота формируются до импорта квартальной истории. Если сначала был импортирован только исторический файл, повторите его после загрузки ФОТ, встреч и текущего портфеля, чтобы расширить сопоставление.

Совпадающий SHA256 уже завершённого файла пропускается; новая версия содержимого создаёт новую запись источника. Для намеренного повторного разбора прежнего хэша после исправления импортёра или расширения пилотного справочника добавьте `--reprocess`. Строки обновляются по стабильным ключам, без удаления таблиц. Не используйте `--reprocess` для обычного повтора неизменившейся поставки.

Импорт фиксирует прогресс порциями; статус источника `running` означает, что обработка ещё идёт. Перед анализом обновляемого ФОТ или встреч дождитесь `complete`: эти таблицы обновляют принадлежащие источнику поля, а не хранят отдельную финансовую историю каждого файла. Снимки предложений хранятся по версиям источников и выбираются независимо.

Фоновое задание хранит PID, время запуска процесса и хэш источника. После перезапуска приложения действующий worker сохраняет статус выполнения. Завершившийся worker сверяется с реестром хэшей. Задание без живого worker и без подтверждённого результата получает сообщение о прерывании и допускает безопасный повтор. Существующие данные не удаляются и процессы не завершаются принудительно.

## Проверки

```sh
"$ATLAS_PYTHON" -B scripts/test_import.py
npm test
./node_modules/.bin/tsx --test scripts/test_backend.ts
npm run typecheck
```

Фикстуры проверяют повреждённый ZIP, повторный хэш, UUID загрузки, восстановление ИНН и коллизии, равные и конфликтные встречи, различие `NULL`/нуля, раздельные суммы снимков, ложный размер листа `A1`, версии штата, выбор последнего завершённого источника, поиск кириллицы, полноту групп сигналов и восстановление заданий. Проверки используют временные базы и синтетические данные. Полный повтор реальных книг для этих тестов не нужен.

Операционные данные доступны через `operationsData(mode)`; метаданные источников — через `sourceStatus(mode)`. Эти функции возвращают агрегаты версий и качества без исходных путей и без ФИО сотрудников. Локальные пути и подробная техническая диагностика остаются в закрытом реестре SQLite.
