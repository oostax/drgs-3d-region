# Привязка зданий к рельефу

## Размеры и масштаб

`building-materials.ts` задаёт единые размеры для MapLibre и Three.js: исходная высота, затем положительная этажность × 3 м, затем профиль назначения. У `neutral` резервная высота **8 м**, а не 2,8 м. Известные гаражи, сараи и другие низкие сооружения сохраняют свои отдельные профили. Явно заданная высота 2,8 м не заменяется на 8 м. Пустое или нулевое `num_floors` не должно скрывать корректное `building:levels`.

Площадь тайлового фрагмента, мобильный режим и уровень детализации меняют сложность оформления, но не высоту здания. Крыша с исходной высотой входит в полный объём; корпус заканчивается у карниза.

## Общая привязка MapLibre / Three.js

`building-terrain.ts` повторяет опорную точку MapLibre 6.7.0: среднее вершин колец, включая отверстия, без повторной замыкающей вершины. Если доступна координата исходного тайла, воспроизводятся внутренний extent 8192 и округление вниз. Первая вершина и геометрический центроид площади не эквивалентны этой точке.

Рельеф проверяется в опорной точке, на вершинах, вдоль длинных рёбер и во внутренних точках контура. Общая неотрицательная поправка поднимает верх корпуса до наивысшей проверенной отметки. `feature-state.atlasTerrainLift` используется и корпусом, и тонкой кровельной поверхностью; та же поправка входит в координаты деталей. Все загруженные части одного ID получают общую поправку, а пространства ID слоёв `building` и `building_part` разделены через `promoteId`.

Исходные высота и этажность при этом не переписываются: на склоне ниже фасада получается фундамент. Для приподнятых частей сохраняется `min_height`; наземный векторный корпус сохраняет штатный цоколь MapLibre.

## Обновление и отсутствие данных

Контроллер не зависит от бюджета декоративных мешей и работает на всех уровнях источника. Проверки разбиты на кадры, снимок привязки публикуется целиком. Догрузка тайлов зданий и DEM, окончание перемещения, изменение размера окна, включение/отключение рельефа и изменение его exaggeration вызывают пересчёт. Неизменившийся результат не инвалидирует геометрию повторно.

`null`, `NaN` и бесконечность не считаются нулевой отметкой. До получения согласованной привязки детальный меш пропускается, остаётся базовая карта. Отрицательные высоты допустимы. При новом снимке рельефа старые детали скрываются до готовности замены; устаревшая работа worker/порционной сборки не должна публиковать старую сцену. Очереди и обработчики освобождаются при удалении карты.

## Проверка

```sh
npm ci
npm test
npm run typecheck
npm run build
```

`tests/building-terrain.test.ts` проверяет резервные 8 м, измеренные низкие здания, совпадение опорной точки с MapLibre, склоны, длинные корпуса, отверстия, тайловые фрагменты, раздельные ID частей, отсутствующий и отрицательный DEM, догрузку, переключение рельефа и пересборку деталей. Остальные тесты архитектуры, worker и LOD также остаются обязательными.

Для визуальной проверки: длинный корпус на склоне; приближение/отдаление и вращение; 2D/3D и рельеф вкл./выкл.; узкое и широкое окно. Запуск локального атласа: `npm run dev`, адрес `http://127.0.0.1:3200`.

## Ограничения

Это адаптация к доступному DEM, не восстановление реального фундамента. Высота неизвестного здания остаётся оценкой. Выборка рельефа ограничена (до 16 шагов на ребро и сетка внутренних точек): узкий пик между пробами, ошибки DEM, отсутствие тайлов и необычно крутой склон нельзя считать проверенными по всей поверхности. Штатная глубина цоколя MapLibre — 10 м; очень большой перепад может требовать отдельной модели фундамента. Тесты геометрии не заменяют визуальную проверку на реальном устройстве.
