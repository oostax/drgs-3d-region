# Правила решения по геопривязке сигнала

Геокодер сначала определяет, есть ли в связанном источнике физическое место события. Наличие слова, похожего на адрес, само по себе не является основанием для координаты: фрагмент должен быть подтверждён текстом источника и относиться к месту события, а не к контакту, автору, примеру или упоминанию прошлого случая.

## Уровни результата

- `building` или `site` назначаются только для единственного подтверждённого объекта с источником геометрии.
- `street` назначается для однозначной улицы, названной в источнике и сопоставленной с локальной геометрией OSM. Это опорная линия улицы, а не дом.
- `settlement` назначается для однозначно названного населённого пункта в пределах территории.
- `territory` используется при нескольких местах, неоднозначности, отсутствии покрытия индекса или отсутствии физического места.

## Отсутствие места в источнике

Если `addressCandidates` и `localityCandidates` пусты, а анализ полезности установил `signalUsefulness.showOnMap=false`, полный текст RSS-статьи не блокирует обработку. Сигнал получает территориальный результат с `locationVerificationMethod=no-location-in-source` и не создаёт ложную точку.

Если адресный кандидат есть, но его нет в подтверждающем тексте, используется `address-candidate-not-supported-by-source`; такой кандидат не передаётся геокодеру и координата не назначается.

## Защита существующих координат

Ручные и доказанные автоматические привязки сохраняются. Повторная обработка допускается только для записи с явной отметкой `untrustedLocationReset` либо для нового задания геокодинга. Старая координата без `coordinateSourceUrl` и геометрии не считается доказанной и может быть сброшена в территориальный fallback с последующей проверкой.

## Контроль качества

После пакетной обработки проверяются: статус каждого задания, уровень точности, наличие координат только при наличии доказательного источника, соответствие `showOnMap`, а также отсутствие новых ошибок и зависших заданий. Территориальный fallback является корректным завершённым результатом, если источник не содержит проверяемого локального места.
