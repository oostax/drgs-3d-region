## Обновление имеющейся локальной копии

Остановить старый сервер сочетанием Ctrl+C и выполнить из папки проекта:

```sh
git switch master && git pull --ff-only origin master && npm ci && npm run dev
```

Открыть `http://127.0.0.1:3200`. Для диагностики доступен `http://127.0.0.1:3200/?diagnostics`.

Требования брать из `package.json` и `.nvmrc`: Node.js >=24.20.0 и <25, npm >=11 и <12. Старое упоминание Node.js 22+ в README недостаточно. При установленном nvm перед `npm ci` выполнить `nvm install && nvm use`.

Команды не содержат `reset --hard`, `clean` или удаления локальных данных. Если имеются конфликтующие изменения исходников, `git pull --ff-only` остановится, а не перезапишет их принудительно. Игнорируемые `.env`, SQLite, PMTiles и кэш не добавлялись в Git и не заменялись.
