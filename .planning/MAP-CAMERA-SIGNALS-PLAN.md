# Карта, сигналы и сцены — 5 сентября

Запрос пользователя принят целиком. Работа идёт параллельно по независимым файлам; существующие изменения сохраняются.

- [x] Камера определяет текущий район после перемещения; сигналы и контекст подгружаются автоматически, камера не отскакивает к центру района. Клик по пустой карте не выбирает муниципалитет. Убрать заливку выбранного Татарстана/района и сигнальную заливку территории.
- [x] Улучшить извлечение адресов, улиц, населённых пунктов и объектов вне Казани. Переобработать реальные источники после резервной копии; измерить покрытие до/после. Неточный сигнал не получает выдуманные координаты.
- [x] За пределами активного Татарстана оставить лёгкую обзорную географию. Ограничить подробные тайлы регионом, сохранить возможность обзора соседних регионов без загрузки их подробностей.
- [x] Заменить непрозрачные круги сигналов компактными группами с цветовым составом. Удалить подписи под ними. Состояние выражает сам маркер, движение связано с актуальностью.
- [x] Банковские группы показывают доли объектов по цветам без подстрочной таблицы. Это состав объектов, не доля рынка.
- [x] Совпадающие события на близком масштабе автоматически разводятся на отдельные доступные маркеры, сохраняя геоякорь и связь с настоящим объектом.
- [ ] По уточнению пользователя сцена занимает всю связанную улицу или периметр здания, а не локальные 32 м у маркера. Подтверждённый охват хранится отдельно от иллюстративного. Для неподтверждённого текущего статуса показывается подробный, но статичный последний известный этап. Карточка объясняет охват.
- [ ] Проверить TypeScript, релевантные TS/Python тесты, HTTP и браузер: регион → район движением камеры → улица → совпадающие маркеры; дневные 2D/3D, архивные/текущие сцены и reduced motion.

Приёмка: нет кликового выбора района и тяжёлой подсветки; контекст следует камере; нет больших кругов с нечитабельной цифрой и постоянных подписей под группами; при приближении доступны все совпавшие события; реальные сцены заметны, но сохраняют мировой размер и подтверждённый охват. Полная достоверная адресная география ограничена содержимым источников.

## Проверка и результат

## Уже проверено

- Автоконтекст: движение от регионального масштаба в Пестречинский район автоматически меняет район и ленту; клика по полигону не требуется. На масштабе Казани показан контекст «город Казань».
- Компактные цветовые группы без чисел и подписей; два совпавших дорожных события на Сары Садыковой развелись при zoom 15.3, выбранный маркер открыл отдельную карточку.
- Исправлена найденная пользователем регрессия: при наклоне далёкие точки за камерой давали длинные цветные связи. Теперь viewport + проверка обратимости проекции + предел экранной и мировой длины; старые смещения сбрасываются на movestart. На Центрально-Мариупольской выполнена браузерная проверка всех категорий, zoom, 2D и возврат в 3D — длинных линий нет.
- Начальная сборка данных раньше занимала 21 858 мс из-за многократной нормализации муниципальных названий при геокодировании обращений. Индекс и мемоизация внутри пакета дали 299 мс при холодной сборке, 51 мс при повторной. HTTP полного регионального запроса в dev: 154 мс; первый ответ без исторических обращений: 17 мс. Это время данных, не полная загрузка GPU-карты.
- Первичный региональный запрос больше не дублируется; исторические обращения подгружаются после готовности карты.
- Полный промежуточный прогон: 287 TS-тестов прошли. Финальная проверка будет повторена после последней доработки сцен.

## Уточнение визуального охвата

Пользователь отдельно указал, что сцены всё ещё маленькие. Первоначальное ограничение 32 м отменено: полная связанная геометрия используется для 3D-иллюстрации, без изменения утверждений источника о фактической длине работ. Задача остаётся открытой до проверки на реальной карте.
