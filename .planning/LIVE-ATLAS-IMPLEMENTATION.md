# Живая карта регионов: реализация

Работа ведётся последовательно одним исполнителем, без сабагентов. Региональная значимость независима от связи со Сбером. Татарстан — первый пилот, ядро и каталог сцен общие для регионов.

- [x] Согласованные SQLite backup с WAL и снимок исходников: private-data/backups/20260904-223050. quick_check всех трёх баз: ok.
- [x] Общие абсолютные пути приложения, worker и importer. Production :3202 подтвердил 11408 организаций, live cursor 193; public не содержит клиентов. Досье сохранены (standalone: 0).
- [ ] Высотные профили дорог/мостов, DEM revision, непрерывные фасады, ресурсные бюджеты.

## Принятые настройки

Бесплатный Mac-пилот, затем сервер. ИНН сопоставляются локально. Новости анализируются через имеющийся доступ к ИИ; требуются endpoint/model и локальный ключ. Telegram: отдельный аккаунт, api_id/api_hash и локальная сессия, разрешения источников учитываются отдельно. Секреты в отчёты не попадают.

Окно 45 дней (30/45/60 и архив), продолжающиеся подтверждённые проекты отдельно. Activity TTL: ЧС 6 ч, ремонт 7 дней, строительство 30 дней; завершённые 14 дней. Отмена не равна завершению. Июльские обращения исторические. Опрос: 1 плохо, 2 нормально, 3 отлично; знаменатель по каждому вопросу.

## Приёмка

Событие без банковской связи остаётся видимым. Недостаточное покрытие источников не означает благополучие. Все 6374 обращения сохраняются, каждое из 247 названий тем получает правило отображения. Public/work изолированы, досье и ручные адреса переживают рестарт. Внешним анализаторам не передаются внутренние строки.

Карта: Казань, Челны, Иннополис и сельский участок; непрерывное движение, день/ночь, DEM после геометрии, сеть/WebGL recovery. Цель M5/16GB, 1440x900: warm overview <=2s, движение >=45 FPS, p95 кадра <=33ms, память выходит на плато. Это будущие критерии, не выполненные замеры.

## Проверено в реализации 4 сентября

- Чтение отсутствующей SQLite возвращает ошибку; создание требует явного create.
- Дороги имеют профиль высот, мосты интерполируют подходы без произвольного +5 м. DEM обновляет сцены. Постепенная сборка фасадов не отменяется каждым движением камеры.
- Каталог v1: 300 рецептов, включая 247 исходных тем и 53 новостных, 34 семейства; галерея /scenes изолирована от событий.
- Реестр вырос до 214 источников: 53 RSS прошли проверку содержимого; 51 Telegram найден по сайтам издателей и ждёт разрешений на получение/показ/ИИ.
- Telegram: один клиент, ограниченная очередь, новые сообщения/правки/удаления, catch-up, history, reconcile и FloodWait. Вход через локальный QR :3211. Реальный end-to-end ещё не подтверждён.
- AnyModel задан локально; запрос к gateway возвращает HTTP 403/error 1010. Не обходить защиту. Анализ по правилам не блокируется.
- Источники/версии не содержат секретов. Секреты в .env.local, права 600; сессия в private-data/telegram.
- 25 Python live tests проходят. Полный TypeScript прогон выявил 2 регрессии, исправления проверяются.
- Full-region Overpass timed out; идёт загрузка по ячейкам. Покрытие нельзя считать полным до сверки.
- Целевые FPS/память/загрузка пока не измерены. Итоговая production/browser проверка впереди.


## Обновление 5 сентября: сцены и привязка объектов

- Общий resolver каталога для карты и галереи: 247 тем обращений, 53 новостных сценария, 34 семейства. Статические объёмные иллюстрации различаются по семейству и имеют подпись состояния. Выбранные архивные обращения получают отдельную иллюстрацию, без активной техники. Территориальные координаты не превращаются в точные объекты.
- Выбранная сцена имеет приоритет в бюджете (12 на desktop, 5 mobile). Геометрия объединяется по материалам, анимация прекращается при скрытии страницы и reduced motion. Масштаб выбора увеличен до 18 для улицы и 18.4 для здания.
- Техника получает право на анимацию только из явной цитаты текущих работ; дополнительно действуют географическая проверка и TTL. Загрузка старых сообщений не обновляет дату свидетельства.
- На production :3202 проверена сцена коммунальных работ у Ямашева, 28: машина, работник, оборудование и ограждение у подтверждённого здания. Галерея укладки асфальта проверена в браузере.
- Зелинского, 102 и Ямашева, 28 сопоставлены с отдельными OSM-контурами; координаты внутри геометрии. Казанский индекс содержит 66850 объектов, покрытие частичное; внешний запрос геометрии кешируется по объекту. Отсутствие совпадения не означает отсутствия дома.
- Подключены три официальных казанских Telegram-источника, 233 публикации обработаны. Авторизация аккаунта локальная. ИИ для этих источников выключен до разрешения; локальные правила работают.
- Исправлены канонические категории, спортивные открытия, ошибочная классификация награждения как строительства; такая публикация удалена из автоматических событий с сохранением исходного документа.
- Проверки: 264 TypeScript и 44 Python теста; построение всех 300 рецептов в восьми состояниях (2400 комбинаций). Это автоматическая проверка геометрии, а не визуальная приёмка всех комбинаций.
- Не закрыты: полное геокодирование Татарстана, все многoадресные публикации, полнота реальных строительных событий, визуальная приёмка всех сцен, end-to-end проверка Telegram edit/reconnect и целевые FPS/память. Последний прежний замер движения около 39 FPS, p95 44.7 мс; норматив 45 FPS/33 мс пока не подтверждён.
