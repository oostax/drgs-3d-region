# Потоковая подготовка карты

Пользователь разрешил реализацию всех трёх предложенных оптимизаций.

1. Выделить единую чистую сборку геометрии. Web Worker возвращает transferable buffers; основной поток сохраняет прежний алгоритм как резервный путь. Отмена и снятие слоя освобождают очередь.
2. Группировать буферы по пространственным участкам. Повторно использовать неизменные GPU-объекты, менять видимую сцену атомарно, ограничить память кеша и удалять только неиспользуемые буферы.
3. После видимой геометрии готовить ограниченное число соседних объектов из уже загруженных тайлов. Отменять устаревшую предварительную подготовку при движении и смене данных.
4. Проверить точное соответствие атрибутов worker/sync, отмену, LRU, повторное использование участков, существующие тесты и production-сборку; выполнить pan/zoom в браузере с диагностикой worker/cache.

Качество: размеры, материалы, текстуры, атрибуты и действующие пределы детализации сохраняются. Предзагрузка не вытесняет видимые ресурсы. Ускорение FPS не заявляется без замеров.

Проверено: 353 теста, TypeScript, production build, Worker в браузере, pan/zoom до z20, возврат 2D/3D. Подробности: [verification.md](../artifacts/render-streaming/verification.md).
