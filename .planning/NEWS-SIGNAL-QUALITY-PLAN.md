# Качество новостных сигналов — 5 сентября 2026

Запрос пользователя зафиксирован как единый поток: расширение источников, фильтрация нерелевантных публикаций, краткая суммаризация, честная геопривязка, оценка полезности и исправление карточек карты.

- [x] Инвентаризировать реестр и текущую базу: 217 кандидатов, 54 разрешённых активных загрузчика, 7 671 сохранённый документ, 1 351 активное событие на момент аудита.
- [x] Сохранять независимую оценку полезности документа/сигнала и показывать на карте по умолчанию только рабочие изменения; полный поток остаётся доступен через «Все публикации».
- [x] Исключить протокольные приглашения к участию в соревнованиях и похожие публикации, ошибочно распознаваемые по слову «открыта».
- [x] Суммаризировать rule-based сигналы до трёх исходных предложений с приоритетом изменения, места, срока и числа; не дописывать факты моделью.
- [x] Сохранять адреса как кандидаты и повышать точность только после отдельного сопоставления с локальной геометрией; территориальная точка не считается адресом события.
- [x] Добавить явную кнопку закрытия карточки сигнала/банка.
- [x] При закрытии банковской панели немедленно снимать режим прозрачности зданий.
- [x] После проверки тестов безопасно пересчитать полезность и краткие сводки сохранённых событий с двумя резервными копиями и переэкспортировать данные.
- [x] Проверить фактическое состояние разрешённых источников: live-worker подтвердил успешную загрузку 111 из 111 разрешённых строк реестра без текущих ошибок. Новые источники активировать только при подтверждённых правах, датах, устойчивом ID и географическом покрытии.
- [x] Проверить в браузере: нерелевантный пример скрыт из «Важного», карточки стали компактнее, у выбранного сигнала и банка есть явное закрытие, здания восстанавливаются без переключения слоёв.

Критерий готовности: карта по умолчанию не показывает редакционный шум; каждый видимый сигнал имеет объяснимую оценку, дату, источник и честный уровень географии; закрытие карточек полностью восстанавливает сцену.
